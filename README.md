## ✨ Ciri-Ciri Utama

| Ciri | Keterangan |
|------|------------|
| 🏢 **Nama Syarikat / Tajuk** | Sesuaikan nama syarikat & tajuk event |
| 🎪 **Nama Event / Sub-Tajuk** | Tambah nama acara atau tema cabutan |
| 🔢 **Nombor Mula & Kuantiti** | Tetapkan nombor permulaan & jumlah tiket |
| 🔤 **Prefix Nombor** | Tambah prefix seperti `TK`, `SRI`, `A` dll |
| 📏 **Label Stub & Entry** | Sesuaikan label bahagian stub dan entry |
| 📐 **Saiz & Dimensi** | Laraskan saiz nombor, tajuk & lebar tiket |
| 🔀 **Nombor Rawak (Shuffle)** | Tiket dicetak dalam susunan rawak |
| 📱 **QR Code pada Tiket** | QR Code automatik mengandungi nombor tiket |
| 👁️ **Live Preview** | Preview tiket masa nyata sebelum download |
| 📄 **Download PDF (A4)** | Export semua tiket dalam format PDF A4 |

## 📖 Panduan Penggunaan

### Langkah 1 — Isi Tetapan Tiket
- Masukkan **Nama Syarikat / Tajuk Utama** (cth: `EVENT PERDANA 2026`)
- Masukkan **Nama Event / Sub-Tajuk** (cth: `LUCKY DRAW 2025`)
- Tetapkan **Nombor Mula** dan **Kuantiti Tiket** yang diperlukan
- Tambah **Prefix Nombor** jika perlu (cth: `TK`, `A`)

### Langkah 2 — Sesuaikan Reka Bentuk
- Laraskan **saiz nombor**, **saiz tajuk**, dan **lebar stub/entry**
- Masukkan label **Stub** dan **Entry** mengikut keperluan

### Langkah 3 — Opsyen Tambahan
- Aktifkan **🔀 Nombor Rawak (Shuffle)** untuk tiket dalam susunan rawak
- Aktifkan **📱 QR Code** jika mahu QR pada setiap tiket *(perlukan internet semasa print)*

### Langkah 4 — Jana & Download
- Klik **`✦ JANA TIKET`** untuk preview semua tiket
- Klik **`↓ DOWNLOAD PDF (A4)`** untuk download fail PDF

## 🛠️ Teknologi Digunakan

- **HTML5** — Struktur halaman
- **CSS3** — Styling & tema gelap profesional
- **Vanilla JavaScript (ES6+)** — Logik jana tiket & shuffle
- **Canvas / DOM API** — Render tiket dinamik
- **PDF Export** — Download terus sebagai PDF A4
- **QR Code API** — Jana QR Code pada tiket
- **Netlify** — Hosting percuma

> 🔒 **Tiada framework, tiada backend, tiada database.** Semua berjalan 100% di browser pengguna.
